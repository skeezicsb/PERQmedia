
These two Shugart 24MB disk images are pre-loaded with POS F.15 patches
through Amendment 3 and work with any version of _PERQemu_ from v0.4.6
and newer.  To use new features such as the Canon printer, QIC tape and
more reliable operation of the RS-232 port, please update to _PERQemu_
v0.9.0 or newer.

  - `f15.prqm`
    A basic binary-only installation with developer tools, demos, apps and games.

  - `f15dev.prqm`
    Contains all of the above, but with full source code and documentation as well.

Consult the _PERQemu_ User's Guide for more information about working
with media files and getting started with POS.
