
## This is POS F.15 Amendment 3.

This complete media set is the culmination of the POS F.15 development effort.
Further work on this unique branch of the POS F tree will continue with F.16.

The _PERQemu_ v0.9.5 release includes the updated hard disk images with all of
the patches through Amendment 3.  Individual floppies are offered in two formats,
or zip archives for more convenient download.  New with Amendment 3 is the QIC tape
installation option.

The entire media set is presented here if you are running an older release or
want to update your PERQ's hard disk without resorting to a full re-installation.
Please see the file Upgrade.md for installation instructions.
